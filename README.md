# PHYS 132 notebooks

In-class notebooks for PHYS 132, Stellar Structure and Evolution (UC Santa Barbara, Fall 2026). Open them on the
course JupyterHub with the links in the Canvas modules.

The solar model in Activities 1, 2 and 3 is BS05(OP) of Bahcall, Serenelli and Basu (2005, astro-ph/0412440). Each notebook
downloads it from https://www.sns.ias.edu/~jnb/SNdata/sndata.html the first time it runs.

Activity 4 uses `gaia_100pc_sample.csv`, a random sample of 10,000 stars within 100 pc from Gaia Data Release 3,
assembled by Brendan Bowler for this course.
